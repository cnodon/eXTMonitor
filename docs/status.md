# 实现与验证状态

日期：2026-11-07。开发设备：Apple M3 Pro / macOS 26.5.1；接收设备：Sony XR-75X95EK / Android 12。

## 已验证

- macOS 主程序与 WidgetKit 扩展编译、签名校验通过；扩展被系统注册。
- Android TV 入口编译和安装；OpenDisplay 电视补丁构建及上游 Android 单元测试通过。
- 9 项控制脚本单元测试通过：地址限制、保留外部会话、离线清理、清理失败保留所有权、仅删除自有虚拟屏、统计过期、不虚构指标、HiDPI 尺寸及独立 ADB 断线后的真实视频统计。
- OpenDisplay 成功建立独立桌面，物理像素 3840×2160，桌面刷新率 60Hz；电视使用 MTK HEVC 硬件解码。
- 动态测试低延迟编码模式约 29–31fps，采集到解码 P50 约 31–36ms；关闭低延迟编码后约 20fps，已恢复低延迟模式。该结果不等于屏幕到屏幕总延迟。
- 电视统计叠层已默认关闭；安装后截图确认画面没有性能数据。
- BlackHole 2ch 已在开发机安装并被 CoreAudio 识别。

- eXTMonitor 桌面实时卡片已显示在 Mac 内置屏幕，点击设置打开控制面板已验证。

## 待验收

- Sunshine 首次配对、4K60 持续串流与音画同步。
- Sunshine 电视音频端到端播放；当前已实现输出选择和自动恢复。
- HDMI 真正接入 Sony 后的分辨率、音频与恢复流程。
- WidgetKit 图库添加与桌面点击链路：扩展已注册，系统图库放置尚未完成。桌面实时卡片作为应用内独立实现，不冒充 WidgetKit 已添加。
- 长时间运行、睡眠唤醒、网络中断恢复、DRM 视频、HDR、不同 Mac/TV 兼容性。

本版本是可运行的集成与设备适配初版，不应描述为已经实现稳定 4K60、120Hz、HDR 或无损音视频。
